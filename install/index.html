LUNA Base を USB で書き込む

LUNA Base v0.9.0 · English

Python も esptool も要りません。PC のブラウザから、LUNA Base を基板(ESP32)に書き込みます。一度入れれば、そのあとのファームや LUNA Base の更新は Wi-Fi で LUNA Store からできます。

用意するもの

  • PC(Windows・Mac・Linux)の Chrome か Edge(スマホ・Safari・Firefox は使えません)
  • データ通信のできる USB ケーブル(充電専用のケーブルでは、ポートが出ません)
  • ESP32 の基板(NS-4000 の基板など。4MB)

書き込み方

  1. 基板を USB で PC につなぎます
  2. 下の「書き込む」を押し、出てきた一覧から基板のポートを選んで「接続」を押します(COM3・USB Serial・CP210x・CH340 などの名前)
  3. 「Install LUNA Base」→「Install」を押します(ここからは英語の画面です)。2〜3 分かかります。終わるまで USB を抜かないでください
  4. 「Installation complete!」と出たら終わりです。基板が自動で起動しないときは、EN(リセット)を押すか、USB を抜き差しします
  5. 続けて、下の「書き込みのあと: Wi-Fi の設定」に進みます

このブラウザでは書き込めません。PC の Chrome か Edge で、このページを開いてください。

このページは https で開く必要があります。

書き込みのあと: Wi-Fi の設定(はじめの 1 回だけ)

基板を自宅の Wi-Fi につなぎます。いったん基板の Wi-Fi に直接つないで設定し、そのあと自宅の Wi-Fi から開きます。前から自宅の Wi-Fi につないで使っていた基板は、設定が残っているので、この手順は要りません(前と同じアドレスで開けます)。

  1. スマホか PC の Wi-Fi の一覧から、「LUNA-BASE-」で始まる名前(例: LUNA-BASE-2DF4)を選んでつなぎます。パスワードはありません。「インターネットなし」と出ても、そのままつないでおきます
  2. ブラウザで http://192.168.4.1 を開きます。LUNA Base の画面が出ます
  3. 画面の下の「Wi-Fi の設定(システムと共有)」を開き、「自宅の Wi-Fi」に自宅の Wi-Fi の名前(SSID)、「パスワード」にそのパスワードを入れて「保存」を押します。ESP32 がつなげるのは 2.4GHz の Wi-Fi だけです(5GHz の名前は選べません)
  4. 少し待つと、「Network Information」の「STA Address:」に、自宅の Wi-Fi での基板のアドレス(例: 192.168.1.23)が出ます。このアドレスを控えてください(メモかスクリーンショット)。「未接続」と出るときは、名前とパスワードを確かめて、もう一度保存します
  5. スマホや PC の Wi-Fi を、元の自宅の Wi-Fi に戻します
  6. 基板の EN(リセット)を押すか、電源を入れ直します
  7. ブラウザで、控えたアドレス(例: http://192.168.1.23)を開きます。LUNA Base と LUNA Store が出ます。LUNA Store から、使うファームを選んで入れます

このアドレスをブックマークしておくと便利です。アドレスが分からなくなったときは、1〜4 の手順で「LUNA-BASE-」につなぐと、もう一度確かめられます。

設定は残ります
基板の中を消去しないので、家庭の Wi-Fi・PIN・架台の設定は残ります。今まで入っていたファームは消えるので、LUNA Base の LUNA Store から入れ直してください。

うまくいかないとき

  • ポートが一覧に出ない: ケーブルを替えてみます。それでも出なければ、USB の変換チップのドライバーを入れます(基板の USB の近くのチップの名前で選ぶ): CP210x(Silicon Labs)・CH340(WCH)
  • 接続・書き込みが始まらない(Failed to initialize など): 基板の BOOT を押したまま EN を押して離し、BOOT を離してから、もう一度「書き込む」を押します
  • 途中で止まった: もう一度書き込めば大丈夫です。書いている途中で止まっても、基板は壊れません
  • ほかのアプリ(Arduino IDE のシリアルモニターなど)がポートを使っていると接続できません。閉じてから試します
