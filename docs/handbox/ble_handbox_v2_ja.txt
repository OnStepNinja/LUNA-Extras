ワイヤレス BLE ハンドボックス ver2(ファーム 2.0.0)

NS-4000(OnStepNinja)を、無線(BLE)で動かす、5 ボタンのハンドボックスです。ESP32 の基板で動きます。
LUNA Store だけで配布します。将来、改良する可能性があります。

■ 操作
- 北・南・東・西 ... 押している間だけ動き、離すと止まります
- 停止 ... 反対方向を同時に押します(北+南、または東+西)
- SEL を短く押して離す(1 秒未満) ... スピードの切り替え(導入 → 移動 → センタリング → ガイド。NS-4000 が音と LED で知らせます)
- LUNA Base へ戻る ... SEL を 5 秒押し続けます(または東+西を 5 秒)。3 秒から LED が速く点滅し、5 秒で戻ります
- スリープ ... つながったまま何も押さないと 7 分、NS-4000 が見つからないと 2 分で、ディープスリープに入ります。SEL を押すと起きます

■ 登録(最初の 1 回)
1. NS-4000 の電源を入れます
2. 30 分以内に、ハンドボックスの電源を入れます。自動でペアリングして、登録されます
3. 登録できるのは 1 台だけです。別のハンドボックスに替えるときは、NS-4000 の File Manager で「Remove Registration」を押してから(NS-4000 の電源を入れてから 30 分以内)、新しいハンドボックスを入れます
- LED: 探している間は 1 秒に 1 回の短い点滅、つながると点灯したままになります

■ 端子(ESP32。NS-4000 の基板の ST4 / ハンドボックスの端子と同じ番号です)
| ボタン・部品 | GPIO |
|---|---|
| 北(赤緯+、DE+) | 33 |
| 南(赤緯-、DE-) | 32 |
| 東(赤経+、RA+) | 35 |
| 西(赤経-、RA-) | 34 |
| SEL(スピード、スリープからの復帰、Base へ戻る) | 39 |
| LED(LOW で点灯) | 25 |
| 電池の電圧の測定 | 14 |

■ 配線
- ボタンは、押すと GND につなぎます
- GPIO 34・35・39 は入力専用で、内部のプルアップがありません。**この 3 つには、10kΩ のプルアップ抵抗(3.3V へ)が必要です**(NS-4000 の基板には付いています)。付けないと、押していないのに押されたと判断して、勝手に動いたり、LUNA Base に戻ったりします
- GPIO 32・33 は、内部のプルアップも使えます。下の回路図では、5 つのボタンすべてに、外付けの 10kΩ のプルアップがあります(R3〜R7)
- LED: 3.3V → 抵抗(回路図では 4.7kΩ)→ LED → GPIO25(LOW で点灯)
- 電池の電圧: 電池+ → 1MΩ → GPIO14 → 1MΩ → GND、GPIO14 から GND へ 0.1µF(回路図のとおり)。NS-4000 の Console で、電圧を見られます
- 電池は、CR123A(約 3V)で動作を確認しました

■ 回路(回路図は、この文の上に出ます)
- モジュール: ESP32-WROOM-32E(U1)。電源: CR123A の電池(3V)1 個と 1000µF のコンデンサ。3.3V の端子に 47µF(C2)と C1
- ボタン: SEL = GPIO39、RR = GPIO34(西)、RL = GPIO35(東)、DD = GPIO32(南)、DU = GPIO33(北)。ボタンは、押すとその端子を GND につなぎます。端子ごとに、3.3V への 10kΩ のプルアップ(R3〜R7)があります
- LED: 3.3V → R1 4.7kΩ → LED → GPIO25(LOW で点灯)
- 電池の電圧: 電池(+3V3 の線)から GND へ、1MΩ を 2 本直列につなぎます。2 本の真ん中を GPIO14 へ、GPIO14 から GND へコンデンサ(0.1µF)。GPIO14 には、電池の電圧の半分が入ります
- RESET: EN の端子に、30kΩ のプルアップ(R2)、1µF(C3)、RESET ボタン(SW1)
- BOOT: BOOT ボタン(SW2)が、GPIO0 を GND につなぎます
- Serial0 の端子(3 ピン。書き込みとログ用): 1 = GND、2 = TX(TXD0)、3 = RX(RXD0)。「LUNA Prog & Comm Adapter v2」(LUNA Store の「データ」)の端子と、同じ番号どうしでつなげます。この端子に電源のピンは無いので、書き込むときは、電池をつないでおきます

■ 作り方と設定(LUNA Base を使います)
1. 回路を作り、電池をつなぎます
2. ハンドボックスの基板に、LUNA Base を USB で 1 回書き込みます(アダプタ、BOOT と RESET の操作、コマンドは、「データ」の「LUNA Base の書き込み方法と使い方」をご覧ください)
3. ハンドボックスの Wi-Fi「LUNA-BASE-xxxx」につなぎ、http://192.168.4.1 を開いて、「Wi-Fi の設定」に自宅の Wi-Fi(2.4GHz)を入れます
4. LUNA Store の「ファーム」で「ワイヤレス BLE ハンドボックス」を選び、「ダウンロード」、「起動」を押します
5. NS-4000 に登録します(上の「登録」をご覧ください)
6. ファームを更新・変更するときは、SEL を 5 秒押し続けて、LUNA Base に戻ります

■ ご注意
- これは、個人が作る試作機向けの配布です。実機では、ESP32 と CR123A で、つながり、各ボタン、停止、スリープからの復帰、LUNA Base へ戻る操作を、確認しました
- 最初は、赤道儀のモーターをつなげずに、動作を確かめてください。通信が 1 秒止まると、動いている間は NS-4000 が自動で止まります
- 回路図は、この文の上に出ます(上の「回路」と「作り方と設定」をご覧ください)
