NS-4000 の ESP32 の基本回路(OnStepNinja_NS4000_v3、2026-11-23)

NS-4000 の基板の、ESP32(ESP32-WROOM-32E)まわりの回路です。ESP32 につながる部品は全部入っています。
NS-5000X のファームも同じ基板・同じ端子で動きます。回路図は、この文の上に出ます。
モーターのドライバ・電源の部分は、この図にはありません。

■ ESP32 の端子と役目
| ESP32 | 信号 | 役目 |
|---|---|---|
| GPIO18 | RA_PLS | 赤経のモーターのパルス |
| GPIO0 | RA_DIR | 赤経のモーターの向き(BOOT のスイッチと共用) |
| GPIO27 | DEC_PLS | 赤緯のモーターのパルス |
| GPIO26 | DEC_DIR | 赤緯のモーターの向き |
| GPIO22 | RA_CD | 赤経のモーターの電流ダウン(H: 電流ダウン、L: 全電流) |
| GPIO19 | DEC_CD | 赤緯のモーターの電流ダウン(H: 電流ダウン、L: 全電流) |
| GPIO39(SVN) | SEL | ハンドボックスの SEL ボタン |
| GPIO34 | RR(RA-) | ハンドボックスのボタン(赤経 -) |
| GPIO35 | RL(RA+) | ハンドボックスのボタン(赤経 +) |
| GPIO32 | DD(DE-) | ハンドボックスのボタン(赤緯 -) |
| GPIO33 | DU(DE+) | ハンドボックスのボタン(赤緯 +) |
| GPIO25 | TLED | 状態の LED |
| GPIO4 | BEEP | 圧電ブザー |
| GPIO21 | SH | カメラのシャッター(ON / OFF) |
| TXD0 / RXD0 | TX1 / RX1 | シリアル(USB・RS232C。書き込みとコマンド) |
| EN | - | RESET のスイッチ |

■ 回路のしくみ
- 電源: 3.3V。47µF(C2)と C1 で ESP32 の電源をならします
- RESET: EN を 30kΩ(R2)で 3.3V へ、1µF(C3)で GND へ。RESET のスイッチで EN を GND に落とすとリセットします
- BOOT: GPIO0 を GND に落とすスイッチ。押したまま RESET すると書き込み待ちになります
- ハンドボックスのボタン(5 つ): 10kΩ ×5(R3〜R7)で 3.3V へ。ボタンを押すと GND に落ちます(押すと L)
- LED: 3.3V → 4.7kΩ(R1)→ LED → GPIO25。GPIO25 が L のとき点灯します(ファームは L で点灯にしています)
- ブザー: GPIO4 → 1kΩ(R8)→ 圧電ブザー → GND
- 電流ダウン: 追尾・停止中は H(電流ダウン)、GOTO 中は L(全電流)。赤緯(GPIO19)は NS-4000 v1.2.24 から。NS-5000X は以前から両方出しています

■ 気をつけること
- GPIO0 は、起動のしかたを決める端子です。電源を入れたときに、ドライバの入力が GPIO0 を L に引くと、書き込み待ちになって起動しません
- GPIO34・35・39 は入力だけの端子で、内部のプルアップがありません。外の 10kΩ が必要です
- 信号はすべて 3.3V です。5V の信号を直接つながないでください
