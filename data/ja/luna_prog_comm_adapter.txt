LUNA Prog & Comm Adapter v2(USB シリアルアダプタ)

3.3V の ESP32 基板のための、小さな USB シリアルアダプタです。1 つで、3 つの仕事ができます。
- 書き込み: esptool で、LUNA Base やファームを書き込む
- 通信: 基板にシリアルのコマンド(LX200 など)を送る(たとえば、LUNA Base へ戻る :&XDL#)
- ログ: 基板がシリアルに出すログを見る
NS-4000 と LUNA の基板で、実機で確認しました。回路図は、この文の上に出ます。

■ 回路のしくみ
- USB: micro USB コネクタ。USB の 5V は、アダプタだけに使います
- CH340N: USB シリアルのチップ。D+ と D- は USB コネクタへ
- 電源の表示: USB 5V → 4.7kΩ → LED。47µF のコンデンサで 5V をならします。CH340N の V3 と VCC にも、コンデンサがあります(値は図に書いていません。CH340N のデータシートをご覧ください)
- TXD(アダプタ → 基板): CH340N の出力は 5V です。直列 200Ω と GND への 330Ω の分圧で、約 3.3V に下げます
- RXD(基板 → アダプタ): CH340N の RXD にそのままつなぎます。基板の 3.3V の信号が、HIGH として読めます
- 端子(3 ピン): 1 = GND、2 = RXD、3 = TXD
- DTR・RTS の線はありません。アダプタだけでは、基板のリセットや書き込み待ちの切り替えはできません

■ 基板へのつなぎ方
| アダプタの端子 | 基板 |
|---|---|
| 1 GND | GND |
| 2 RXD | 基板の TX(TXD0) |
| 3 TXD | 基板の RX(RXD0) |
- LUNA Store の BLE ハンドボックスの回路図の端子は、同じ番号(1 GND、2 TX、3 RX)です。同じ番号どうしをつなげます
- アダプタは、基板に 3.3V も 5V も送りません。基板は、自分の電源や電池で動かします。GND は共通にします
- 3.3V の基板だけにつなぎます。RXD に 5V の信号をつながないでください

■ ファームや LUNA Base を書き込む
1. アダプタを基板につなぎ、基板の電源を入れます
2. 手で書き込み待ちにします: BOOT を押したまま、RESET(EN)を押して離し、BOOT を離します
3. 書き込みます(COM6 は、自分の PC の番号に替えます。ファイルとアドレスは、「LUNA Base の書き込み方法と使い方」をご覧ください)。

  python -m esptool --chip esp32 --port COM6 --baud 115200 --before no_reset write_flash 0x0 LUNA_Base_install.bin

4. 終わったら、RESET(EN)を 1 回押して起動します。書き込みは 115200bps です
- COM ポートの番号は、Windows のデバイスマネージャーで見られます。出ないときは、CH340 のドライバを入れてください

■ 通信とログの見かた
- シリアルターミナルを使います(Tera Term、PuTTY、Arduino のシリアルモニタなど)。ローカルエコーは無しです
- LUNA Base と起動のメッセージ: 115200bps
- NS-4000 のシリアルコマンド(LX200 の形): 9600bps。コマンドの最後は # で、改行は不要です。例: :&XDL# で、基板が LUNA Base に再起動します(GOTO 中は不可)
- esptool を使う前に、ターミナルを閉じてください。COM ポートは、1 つのプログラムしか使えません
