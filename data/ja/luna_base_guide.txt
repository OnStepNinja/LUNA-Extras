LUNA Base の書き込み方法と使い方(LUNA Base v0.8.4)

LUNA Base は、ESP32 基板に入れる小さなストアです。USB で 1 回だけ書き込みます。
そのあとは、LUNA Store からファームやアプリを選んで、Wi-Fi で入れられます。更新のたびに USB は要りません。

■ 用意するもの
- フラッシュ 4MB の ESP32 基板(たとえば NS-4000 の基板、LUNA Store にあるハンドボックスの基板)
- 基板のシリアル端子につなぐ USB シリアルアダプタ: 「LUNA Prog & Comm Adapter v2」(回路図は LUNA Store の「データ」にあります)、または 3.3V の USB シリアルアダプタ
- Python と esptool を入れた PC(pip install esptool)
- GitHub の OnStepNinja-NS4000 の Releases にある LUNA_Base_install.bin(日本語版。LUNA_Base_install_en.bin は英語版です)
- インターネットにつながる 2.4GHz の自宅の Wi-Fi。ESP32 は 5GHz につながりません

■ 1. LUNA Base を書き込む(最初の 1 回)
1. アダプタを基板につなぎます: GND どうし、アダプタの TXD → 基板の RX、アダプタの RXD → 基板の TX。アダプタは基板に電源を送りません。基板は、自分の電源や電池で動かしてください
2. 基板を書き込み待ちにします: BOOT ボタンを押したまま、RESET(EN)を押して離し、BOOT を離します。(このアダプタには自動リセットの線が無いので、手で行います)
3. 次のコマンドで、ファイルを 1 回書き込みます(COM6 は、自分の PC の番号に替えてください)。

  python -m esptool --chip esp32 --port COM6 --baud 115200 --before no_reset write_flash 0x0 LUNA_Base_install.bin

   esptool 5 では、no-reset・write-flash の書き方も使えます
4. 終わったら、RESET(EN)を 1 回押します。LUNA Base が起動します(ブザーのある基板は、3 回鳴ります)
- 起動のログは、シリアルポートを 115200bps で開くと見えます。「LUNA Base 0.8.4  AP LUNA-BASE-xxxx  system: ...」の行が出ます

すでにファームが入っている基板に書くとき
- 残るもの: ファーム、アプリ、Wi-Fi の設定、PIN
- 消えるもの: NVS の領域に保存した設定(たとえば NS-4000 の架台の設定、BLE ハンドボックスの登録)。ファームが起動したあと、ハンドボックスを登録し直してください
- 先に LUNA Base が起動します。「起動」を押すと、ファームがまた動きます

■ 2. 最初の設定
1. スマホか PC で、基板の Wi-Fi「LUNA-BASE-xxxx」(xxxx は基板のアドレスの下 4 桁。パスワードなし)につなぎ、http://192.168.4.1 を開きます
2. 「Wi-Fi の設定」を開いて、自宅の Wi-Fi(2.4GHz)の名前とパスワードを入れます。基板の名前と、4 桁の PIN も決められます。「保存」を押すと、基板が自宅の Wi-Fi につながります
3. 「Network Information」に、AP SSID・AP Address・STA Address が出ます。同じ Wi-Fi の機器からは、STA Address でも開けます
- Wi-Fi の設定は、ファームと共有です。1 回入れれば、両方で使えます

■ 3. 画面の見かた(上から)
- お知らせ: LUNA Project からのお知らせ
- ファームウェア: 入っているファームと、「起動」ボタン。「更新あり x.y.z」もここに出ます
- アプリ(ダウンロード済): 基板に入れたファイル、空き容量、「削除」
- LUNA Store: 「ファーム」「アプリ」「データ」のタブ。項目を選んで、説明を読み、「ダウンロード」を押します(文書は「見る」)。「更新」で目録を読み直します。基板が、自宅の Wi-Fi から GitHub へ取りに行きます
- PCファイル: PC・スマホにあるファーム(.bin)を選んでアップロードします。製品の印と CPU の種類を、先に確かめます
- Network Information と Wi-Fi の設定
- 写真や README の文章は、スマホ・PC が読みに行きます。そのため、スマホ・PC がインターネットにつながっているときだけ出ます

■ 4. ファームを入れる
1. LUNA Store の「ファーム」のタブで、1 つ選んで「ダウンロード」を押します。今のファームと置き換わります(設定・Wi-Fi・アプリは残ります)
2. 「完了」と出るまで待ちます。ダウンロード中は電源を切らないでください。失敗したり、電源が切れたりしても、LUNA Base が自動でまた起動するので、USB 無しでやり直せます
3. 「起動」を押します(「今すぐ起動しますか」に OK でも同じです)。画面が、ファームの画面に自動で切り替わります
4. あとで更新するときは、LUNA Base をまた開き、新しい版の「ダウンロード」を押して「起動」します
- ファームは 1.875MB に収まるものです。入らないものは、薄く表示されます

■ 5. LUNA Base へ戻る
- ファームの Console の「LUNA Base」ボタン(NS-4000、NS-5000X)
- シリアルコマンド :&XDL#(NS-4000 は 9600bps)。赤道儀が止まっているとき、追尾中は使えます。GOTO 中は断られます
- BLE ハンドボックス: SEL を 5 秒押し続けます

■ 6. うまくいかないとき
- 自宅の Wi-Fi の設定を間違えて、基板の Wi-Fi に入れない: LUNA Base 0.8.4 以上、NS-4000 1.2.8 以上なら、基板の Wi-Fi はいつでも使えるので、つないで設定を直してください。それより古いファームは、自宅の Wi-Fi を探し続けて、基板の Wi-Fi がほとんど出ません。シリアル(アダプタ)で :&XDL# を送ると LUNA Base に戻れるので、そこで Wi-Fi の設定を直し、ファームを更新してください
- LUNA Store が空: 自宅の Wi-Fi とインターネットを確かめて、「更新」を押してください
- 5GHz の SSID は使えません。ルーターの 2.4GHz の SSID にしてください
- ファームが起動しない: LUNA Base が自動で戻り、そう表示します
- 書き込んだあとに LUNA Base が起動しない: RESET(EN)を 1 回押し、115200bps でログを見てください。ログが無ければ、もう一度書き込みます

■ 7. LUNA Base 自身の更新
LUNA Base は、自分自身を更新できません。新しい LUNA_Base_install.bin を、同じコマンドでもう一度書き込みます(1 を参照)。ファーム、アプリ、Wi-Fi の設定、PIN は残ります。NVS の設定は消えます
